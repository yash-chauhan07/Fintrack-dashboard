# FinTrack Dashboard

A clean and interactive finance dashboard built with React, JavaScript, and Tailwind CSS.

## Features

- **Dashboard Overview**: 
  - Summary cards for Total Balance, Income, and Expenses.
  - Interactive Area Chart showing balance trends over the last 7 days.
  - Pie Chart displaying spending breakdown by category.
- **Transaction Management**:
  - Full list of transactions with search and type filtering.
  - Admin users can add, edit, and delete transactions.
  - Viewer users have read-only access.
- **Role-Based UI**:
  - Toggle between **Admin** and **Viewer** roles to see how the UI adapts.
- **Insights**:
  - Automatically calculated insights like Top Spending Category, Savings Rate, and Monthly Income.
- **Modern UI/UX**:
  - Fully responsive design for mobile and desktop.
  - Dark Mode support with system persistence.
  - Smooth animations using `motion`.
  - Data persistence using `localStorage`.
